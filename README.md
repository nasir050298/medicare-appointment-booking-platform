# MediCare Connect — Healthcare Appointment Booking Platform

A professional healthcare appointment booking platform built with React, TypeScript, Tailwind CSS, Zustand, React Hook Form-ready structure, Zod-ready structure, Recharts, and role-based dashboards.

It includes doctor search, doctor profile pages, appointment booking, patient dashboard, doctor schedule management, prescription UI, medical records, payment/status pages, notifications, admin analytics, and responsive healthcare-focused UI.

## Demo Accounts

- Patient: `patient@medicare.com` / `demo123`
